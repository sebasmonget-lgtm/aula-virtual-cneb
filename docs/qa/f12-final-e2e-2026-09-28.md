### Gates que siguen sin aceptación

- **Año completo:** no se ejecutó una secuencia nueva P1→P2→P3→P4→cierre anual exclusivamente por UI. El clon tiene solo seis hechos diagnósticos y una actividad confirmada; no hay base pedagógica para resolver todos los pares anuales. El calendario QA controlado para este clon tampoco está configurado. No se inventaron valoraciones ni se retiraron competencias para pasar el gate.
- **Staging Supabase:** la usuaria confirmó que todavía no existe un staging nuevo independiente. La regla del proyecto impide reutilizar las cuentas actuales. Por ello no se ejecutaron migraciones desde cero, RLS/aislamiento de dos docentes ni Storage privado/URLs reales.
- **Carpeta real:** en Chrome, al pulsar «Elegir carpeta y sincronizar» el navegador devolvió `The user aborted a request` antes de seleccionar directorio. No existe `.ayni-sync.json` real verificado, ni pruebas nativas de incremental, conflicto o reanudación. La UI informó «ZIP descargado», pero el evento de descarga y un ZIP guardado en el equipo no pudieron verificarse; solo se comprobó el ZIP y sus hashes directamente desde la API local.
- **Word visual:** se intentó el renderizador exigido por la habilidad de documentos con el runtime integrado. Falló antes de renderizar porque no existe `soffice.exe` de LibreOffice en el bundle/PATH. No se sustituyó por una instalación externa no verificada. La vista HTML de Documentos no equivale a inspección visual del DOCX. Siguen pendientes muestras renderizadas de plan, proyecto, actividad, evaluación/reporte y cierre cuando exista un artefacto real.
- **Móvil:** no se usó dispositivo físico ni se subieron archivos desde móvil. No se afirma equivalencia de una viewport simulada.
