# Checklist de release

- [ ] Cuentas nuevas y aisladas para Supabase y hosting.
- [ ] Variables de entorno cargadas fuera del repositorio.
- [ ] Migraciones probadas en entorno local o staging.
- [ ] RLS validada con dos docentes diferentes.
- [ ] Typecheck, lint, tests y build correctos.
- [ ] Flujos de autenticación, aula y evidencia probados en móvil y escritorio.
- [ ] Revisión de secretos y datos de menores.
- [ ] Commit limpio identificado antes del deploy.
- [ ] Preview/staging validado.
- [ ] Smoke test posterior y rollback documentado.
