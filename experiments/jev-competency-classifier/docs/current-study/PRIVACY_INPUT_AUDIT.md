# Auditoría local de entradas DEV tras privacidad

El filtro común se mantiene congelado. Este inventario compara bytes/texto; no usa gold para reconstruir entradas y no llama a modelos. Algunos reemplazos de mayúsculas ocultan verbos, otros ocultan nombres. No se modifica el comportamiento medido.

Entradas permitidas alteradas: 41/76.
