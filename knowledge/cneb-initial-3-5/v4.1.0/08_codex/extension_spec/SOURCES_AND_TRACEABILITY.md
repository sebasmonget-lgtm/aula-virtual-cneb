## Fuentes históricas

Las publicaciones previas al CNEB actual se incorporan **solo como conocimiento didáctico compatible**. No pueden:

- reemplazar nombres de competencias/capacidades actuales;
- proporcionar estándares/desempeños canónicos;
- resolver conflictos normativos;
- aparecer como texto curricular vigente.

Cuando haya conflicto, prevalece la jerarquía existente de Ayni: norma vigente → CNEB → Programa Curricular de Inicial → orientaciones recientes → orientaciones compatibles.
