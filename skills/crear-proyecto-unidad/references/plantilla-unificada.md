# Proyección a la plantilla de Proyecto/Unidad

La plantilla DOCX se llena mediante código después de confirmar el Plan Maestro. Para redactar el contenido formal, produce textos breves y coherentes para la situación significativa, fundamentación, metodología, evaluación formativa, colaboración con las familias, apoyos para la diversidad y cierre previsto.

El título, fechas, propósito, competencias, criterios generales, ruta fechada, recursos y datos institucionales se copian de los datos confirmados. No replantees ni agregues actividades. Los campos de planificación con los niños, evidencias reales, valoración y ajustes posteriores permanecen vacíos hasta que se realicen.
